ホーム/Components

Filter Chip

タグや単語でコンテンツを絞り込むトグル可能なチップです。選択と同時に結果がその場で更新される複数同時選択の絞り込みに使います。

state

1つ目のチップをクリックすると選択状態を切り替えられます

状態一覧

hover / focus / pressed はカタログ用に固定表示しています（実際の画面ではマウス・キーボード操作で出ます）

通常hoverfocuspresseddisabled
未選択
選択

使用法

OK

  • 選択状態は aria-pressed="true|false"
  • 件数表示は filter-chip-count

NG

  • 単一選択しか許さない設問に並べない → radio
  • 送信やページ遷移を伴う絞り込みに使わない → checkbox/select + 明示的な適用ボタン（WCAG 3.2.2）

必須対応

  • 選択状態を aria-pressed="true/false" で表し、トグルで更新する
  • 選択は色だけでなくチェックマークでも示す
