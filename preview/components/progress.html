使用法

OK

  • 進み具合を数字でも示す（progress-label か、円の中の %）
  • 色の意味: success は完了、warning は遅れ、negative は失敗・超過。既定はチャコール
  • 円・半円はダッシュボードの指標、バーはフォーム・アップロード・一覧の行内

NG

  • 終わりが分からない処理に使わない → input-group-loader や btn の data-loading
  • 色の違いだけで状態を伝えない

必須対応

  • バーはネイティブの <progress value max> を使い、aria-label か <label for> で名前を付ける
  • 円・半円は role="progressbar" と aria-valuenow / min / max、aria-label
  • 塗りと下地は 3:1 以上
