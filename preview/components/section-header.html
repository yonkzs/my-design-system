使用法

OK

  • 見出しはページ内の階層に合った見出し要素（h2 等）にする
  • 右側は「検索 → 補助ボタン → 主ボタン」の順。主ボタンは1つまで
  • 表示の切り替えは btn-group、操作が多いときは「その他」にまとめる

NG

  • ページタイトルに使わない → typo-3xlarge の h1
  • 右側の操作を3つ以上並べない

必須対応

  • 見出しは見出し要素で、レベルを飛ばさない
  • セクションを <section aria-labelledby> で包む
  • アイコンだけのボタンに aria-label
