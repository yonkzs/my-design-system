ホーム/Components

Date Picker

日付を入力する欄と、開いて選ぶカレンダーです。日付の並び・月送り・開閉はプロダクト側の JS が描き、DS はその見た目と状態の表し方を決めます。

入力欄

Starter の Date Picker（State=closed / open）

閉じている
納品日

例: 2026/10/07

開いている

2026年10月

日月火水木金土

カレンダー

Starter の Calendar / Dates

1日の選択

2026年10月

日月火水木金土
aria-selected / aria-current="date"
期間の選択

2026年10月

日月火水木金土
開始・終了は aria-selected、間は data-range="middle"
選べない日

2026年10月

日月火水木金土
disabled（休業日など）

使用法

OK

  • 入力欄は直接入力も受け付け、カレンダーは補助にする（書式は support text で示す）
  • 選べない日は disabled、前後の月の日は data-outside
  • 期間は開始日・終了日に aria-selected、間の日に data-range="middle"

NG

  • 生年月日など遠い過去の日付をカレンダーだけで選ばせない
  • 土日を色だけで区別しない

必須対応

  • 開くボタンに aria-label と aria-expanded
  • カレンダーは <table role="grid">、曜日は <th scope="col" abbr>、日付は <button>（aria-label は完全な日付）
  • 矢印キーで移動・Enter で選択・Esc で閉じてフォーカスを開くボタンに戻す（JS 側）
  • 日付セルは 32px（Starter の 24px より大きくしている）
