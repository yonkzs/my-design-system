Avatar

component

人・組織を表す丸い画像です。写真・イニシャル・アイコンの3種類と、状態の点・所属のロゴ、名前と並べる版、重ねて並べる版があります。

size

Starter の md / lg / xl / xxl / huge

sm / md / lg / xl / 2xl
24 / 36 / 48 / 64 / 96px

種類・状態の点

写真 / イニシャル / アイコン
山
状態の点
山佐鈴高
online / idle / busy / offline

名前と並べる・重ねて並べる

avatar-label
山田 花子営業部 マネージャー
avatar-group
山佐鈴+3
+N で残りの人数

使用法

OK

  • 写真が無い人はイニシャル（日本語名は姓の1文字）、人以外はアイコンにする
  • 表の行・コメントは sm、一覧のカードは md、詳細の見出しは lg 以上
  • 3人を超える担当者は avatar-group で重ね、残りは「+N」で示す

NG

  • 状態を点の色だけで伝えない → aria-label にも状態を含める
  • 1つの一覧の中でサイズを混ぜない

必須対応

  • 写真の alt に人名。名前を横に表示しているときは alt=""
  • イニシャル・アイコンだけのときは role="img" と aria-label
  • 押せるアバターは button / a で包む（フォーカスリングはその要素に出る）
