使用法

OK

  • 受け付ける形式と上限サイズを file-upload-hint に必ず書く
  • 狭いフォームの中は file-upload-compact、添付が主役の画面は既定
  • アップロード中は行ごとに progress、失敗は file-item-error と直し方を出す

NG

  • 失敗の理由を「エラー」だけにしない
  • アップロード中に画面全体を止めない

必須対応

  • <input type="file"> を受け口いっぱいに重ね、クリック・キーボードでも選べるようにする
  • 入力に aria-describedby で形式・上限を関連付ける
  • 結果は role="status"（成功）/ role="alert"（失敗）で読み上げる
