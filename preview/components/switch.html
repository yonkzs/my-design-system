Toggle Switch

設定のON/OFFを切り替え、結果が即座に反映されるフォーム部品です。送信ボタンで確定する項目は checkbox を使います。

size / state

md, off
md, on
sm, on
disabled

補足文

Starter の Switch Label の subtext

補足文

入力のたびに下書きを保存します

switch-field + switch-desc

状態一覧

hover / focus / pressed はカタログ用に固定表示しています（実際の画面ではマウス・キーボード操作で出ます）

通常hoverfocuspresseddisabled
off—
on—

使用法

OK

  • input type="checkbox" role="switch" を switch-label で囲み、ラベル全体を押せるようにする
  • 切り替えた結果は即座に反映する（保存ボタンを待たない設定に使う）

NG

  • フォーム送信で確定する入力に使わない → checkbox を使う
  • ラベルを状態で言い換えない（「ONにする」等）→ 機能名で固定する

必須対応

  • 各スイッチにラベルを switch-label で内包 か aria-labelledby で関連付ける
  • role="switch" で「オン/オフ」が伝わる。状態を色だけで表さない
  • switch-sm(高さ20px)はラベル併用でタップ領域24px以上を確保
