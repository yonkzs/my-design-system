Input Group

component

入力欄の前後に、単位・記号・アイコン（addon）、くっついた選択やボタン（tab）、読み込み中の表示（loader）を付けた1行入力です。前後に何も付けないときは input を使います。

使用法

OK

  • 「¥」「円」「https://」など、入力値の解釈を助ける短い文字は addon にする
  • 入力と一体で選ぶ値（国番号・単位の切り替え）は tab（select）にする
  • 入力値と一緒に実行する操作（確認・コピー）は tab（button）にする
  • 裏で確認している間（重複チェックなど）は loader を出す

NG

  • addon に操作や長い説明を入れない → 説明は field-support-text、操作は tab（button）
  • 前後の両方に tab を付けない（前後の一方に1つまで）
  • 検索欄に使わない → search-input

必須対応

  • ラベルは中の input に付ける（<label for> か aria-label）
  • 単位など意味のある addon には id を振り、input の aria-describedby で関連付ける（addon の文字は読み上げのラベルに含まれない）
  • tab の select / button にもそれぞれ aria-label を付ける
  • loader は role="status" とし、中に sr-only の文言（例: 確認中）を入れる
  • フォーカスは枠全体に info 青のリング（:focus-within。DS担保）
